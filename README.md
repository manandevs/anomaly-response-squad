## 📡 Transmission Data
This repository contains the source code for the **Anomaly Response Squad**—a high-fidelity, cyberpunk-themed landing page. It is designed to showcase modern front-end techniques, focusing on immersion, interactivity, and performance.

## ⚡ Tech Stack & Arsenal
*   **Core:** Semantic HTML5, CSS3 (Custom Variables), Vanilla JavaScript.
*   **Motion Engine:** [GSAP](https://greensock.com/gsap/) (ScrollTrigger, QuickTo).
*   **Visualization:** [Three.js](https://threejs.org/) (Interactive 3D Globe).
*   **Typography:** Google Fonts (Orbitron & Rajdhani).
*   **Icons:** Boxicons.

## 🎯 Key Features
*   **Fluid Cursor System:** A custom "Dot & Follower" cursor with lag effects and interactive hover states.
*   **Tactical Animations:** Elements fade up, numbers crunch up, and text glitches on load.
*   **Interactive 3D Globe:** A rotating wireframe earth that tracks mouse movement.
*   **Redacted Intel:** Text reveals that trigger on scroll.
*   **Responsive Grid:** Background grid animation and mobile-adaptive layout.
